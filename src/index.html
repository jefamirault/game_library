Search syntax
mario kartwords in the title, file name, developer, publisher, genre or credits (all must match)
"super mario"an exact phrase

t:mario t:"of the"title only (also title:)
c:gba c:snes c:sega c="game boy"console (also console:). Short names match that console exactly (gb gbc gba nes snes n64 gc ds md psx …); other text matches part of the name; c= is the whole name. c:none has no console set
dev:nintendo pub:capcomdeveloper (also developer:) or publisher (also publisher:)
by:konamideveloper or publisher
a:miyamoto a:"koji kondo"credits: people and roles (also credits:)
g:platform g:rpggenre (also genre:; rpg means role-playing)
d:dungeondescription (also desc:)
notes:betanotes
f:usa ext:gbcfile name (also file:); file extension
year:1996 year<2000 date>=1995-06release year or date (also y: released:; = < > <= >=). year:199 is the 1990s
added>=2026-09date added to the library
p:2 p>=3 p=1players (also players:): p:2 supports two players; comparisons use the most players
size<1mb size>=32mdownload size (kb mb gb; a bare number is MB)
has:cover has:credits has:noteshas a cover, credits, notes, description (has:desc) or console; has:info has any game info
c:gba or c:gbc (c:nes or c:snes) dev:nintendoeither side matches; parentheses group terms

Terms are case-insensitive. A game missing a value (no release date, say) never matches a term on it: year<2000 leaves out undated games, and -year<2000 keeps them. Keys: / search, Esc close.
